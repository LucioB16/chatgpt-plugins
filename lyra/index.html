Lyra

Better prompts for any AI.

Lyra turns rough instructions into structured, copy-ready prompts while preserving your original intent, requirements, and exclusions. It adapts to ChatGPT, Claude, Gemini, research workflows, and coding agents.

What you can do

  • Refine quickly: clarify an incomplete request and get a cleaner prompt.
  • Research with constraints: define sources, exclusions, comparison criteria, and an expected report.
  • Bootstrap projects: design prompts for a coding agent to discover dependencies, set up a project, implement milestones, and verify progress.

How it works

Tell Lyra the goal and, optionally, the AI platform you plan to use. Choose a quick rewrite or a more thorough optimization. By default, Lyra produces the improved prompt; it does not carry out the underlying task.

Lyra is a skills-only plugin. It does not operate an independent backend or require an account with the developer. Availability in the public plugin directory depends on OpenAI's review and publication process.
