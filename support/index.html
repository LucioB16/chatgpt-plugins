Support

Questions, bug reports, and feature suggestions for Lyra or Iterloom.

Both plugins are independently maintained by Lucio Bottacin. The public issue tracker below is the support contact channel for these projects.

Open a support issue on GitHub →View existing issues

What to include

  • Which plugin you are using (Lyra or Iterloom).
  • What you expected, what happened, and steps to reproduce the problem.
  • Relevant version details, if known.
GitHub issues are public. Do not post conversation exports, private messages, passwords, API keys, IDs, health or financial information, or other sensitive data. Redact screenshots before sharing them.

Platform and billing issues

If the problem concerns your ChatGPT subscription, account, payment, or platform-level privacy controls, use the support channel provided by OpenAI rather than this project tracker.

Support channel: github.com/LucioB16/chatgpt-plugins/issues
